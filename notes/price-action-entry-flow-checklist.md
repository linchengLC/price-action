# Price Action 进场流程对照手册

这份手册是盘中对照版，不是理论笔记。

目标只有一个：看到一个可能的进场机会时，按固定顺序判断它能不能做、该怎么做、什么时候不能做。

> 只要说不清 `market condition`、位置、trigger、止损、目标和仓位，这笔单就先不做。

## 0. 先做三秒钟排除

下面任意一条成立，先不要下单：

- 我只是觉得“涨太多了 / 跌太多了”
- 当前在区间中间，没有明显位置优势
- 我不知道这是 `trend` 还是 `trading range`
- 我说不出明确 trigger，只是怕错过
- 我还没想好 `initial stop`
- 我还没想好第一目标位 `target`
- 我不知道这笔是 `scalp` 还是 `swing`
- 止损距离变大了，但仓位没有变小
- 我想做强趋势后的第一次反转，还没有等 `second entry`
- 我想做反转，但没有强势 `signal bar` 和突破单触发
- 我打算靠加仓摊低一个已经失效的 setup
- 我刚亏完一笔，还没有等 2-3 根 K 重新判断市场周期
- 经济日历显示重大事件即将公布，或盘面刚出现无法解释的异常波动

如果过不了这一关，最好的操作是等待下一根 K，而不是强行找理由。

## 1. 第一步：判断市场环境

先不要看单根 K 线，先问：现在属于哪种环境？

| 环境 | 盘面特征 | 默认思路 |
| --- | --- | --- |
| `trading range` 震荡区间 | 上去被卖、下来被买，K 线重叠多，突破常失败 | 上沿找空，下沿找多，中间少动 |
| `bull trend / Always In Long` 上涨趋势 | 高低点抬高，回调浅，突破后有 `follow-through` | 优先等回调做多，不急着猜顶 |
| `bear trend / Always In Short` 下跌趋势 | 高低点下压，反弹弱，跌破后有 `follow-through` | 优先等反弹做空，不急着抄底 |
| `broad channel` 宽通道 | 有方向，但上下摆动很大，像倾斜震荡 | 通道边缘和失败突破更重要 |
| `narrow range day` 窄震荡日 | 全天波动小，平均 K 线小，突破跟随差 | 只做小目标 `scalp`，或少做 |

最常见错误：

- 把 `trading range` 当趋势追突破
- 把强趋势第一次回调当大反转
- 把宽通道当顺滑趋势
- 把窄区间日当大波段日

## 2. 第二步：判断当前位置

位置比单根 K 线更重要。

```text
区间上沿：优先找空 / 不追多
┌────────────────────┐
│                    │
│     中间：少动      │
│                    │
└────────────────────┘
区间下沿：优先找多 / 不追空
```

### 可以优先看多的位置

- `trading range` 下沿或下方三分之一
- 下跌后出现 `sell climax`
- 向下突破后没有 `follow-through`
- 出现 `failed breakout`、`higher low`、`double bottom`
- 大级别偏多，小级别回调给出像样 trigger

### 可以优先看空的位置

- `trading range` 上沿或上方三分之一
- 上涨后出现 `buy climax`
- 向上突破后没有 `follow-through`
- 出现 `failed breakout`、`lower high`、`double top`
- 大级别已经转弱，小级别反弹失败

### 位置不好的情况

- 区间中间
- 刚刚连续几根大 K 后追进去
- 入场点离止损太远，盈亏比变差
- 方向可能对，但已经没有好价格

位置不好不代表行情不会走；它只代表这笔交易对你不友好。

## 3. 第三步：给机会分类

看到机会后，先把它放进一个类型里。分类不清，就不要进。

| 类型 | 能做的前提 | 常见处理 |
| --- | --- | --- |
| 区间下沿做多 | 下沿附近，空头下破失败，有多头 trigger | 多数先按反弹或 `scalp`，别直接幻想大趋势 |
| 区间上沿做空 | 上沿附近，多头上破失败，有空头 trigger | 第一目标常是区间中部、缺口或 EMA 附近 |
| 趋势回调顺势 | 已经 `Always In Long/Short`，回调没有破坏趋势 | 等 signal bar 或突破触发，目标可更远 |
| `failed breakout` 反手 | 突破后快速失败，没有跟随 | 多数按 `scalp`，要快进快出 |
| `sell/buy climax` 后反向 | 趋势尾端加速，追随者开始失望 | 先等 trigger，不要只因“大”就反向 |
| 强趋势后反转 | 到目标位，第一次反转失败，第二次信号更好 | 胜率低，必须要好 `reward/risk` |
| 宽通道加速突破失败 | 通道末端突破后 5 根 K 内失败，小周期转向 | 可以看反转波段，但仓位要按止损重算 |
| 窄区间日 `scalp` | 平均 K 小，边缘位置，突破跟随差 | 目标就是一根平均 K，不要拿成 swing |

## 4. 第四步：等 trigger，不要用背景直接入场

背景只说明“可以开始关注”，trigger 才说明“现在可以动手”。

### 常用多头 trigger

- 区间下沿出现 `bull signal bar`
- 向下 `breakout` 失败后快速收回区间
- `double bottom` 或 `higher low`
- 强趋势里回调结束后继续上破
- `sell climax` 后不再创新低，并出现跟随买盘

### 常用空头 trigger

- 区间上沿出现 `bear signal bar`
- 向上 `breakout` 失败后快速跌回区间
- `double top` 或 `lower high`
- 强下跌趋势里反弹结束后继续下破
- `buy climax` 后不再创新高，并出现跟随卖盘

### trigger 不合格的情况

- 只有一根很大 K，但位置很差
- 只有影线，没有后续确认
- 突破后马上停住，没有 `follow-through`
- 信号 K 太大，导致止损太宽
- trigger 出现时，目标空间已经不够

## 5. 第五步：看 follow-through

进场前后都要看 `follow-through`。

```text
突破以后继续同方向推进 = follow-through 好
突破以后停住、重叠、反向收回 = follow-through 差
```

### 有 follow-through，可以考虑继续拿

- 多头突破后连续收在高位
- 空头跌破后连续收在低位
- 回调小、重叠少、反向 K 没有力量
- 趋势目标还没到

### 没有 follow-through，要降级处理

- 趋势单降级成 `scalp`
- 顺势预期降级成区间预期
- 不再追突破
- 已有利润时优先保护一部分
- 还没进场就直接放弃

## 6. 第六步：决定这是 scalp 还是 swing

这个决定必须在入场前做，不能入场后再看心情。

| 问题 | 如果答案是是 | 更像 |
| --- | --- | --- |
| 今天是窄区间日吗？ | 是 | `scalp` |
| 入场来自 `failed breakout` 吗？ | 是 | 多数 `scalp` |
| 目标只是一根平均 K 或补小缺口吗？ | 是 | `scalp` |
| 大级别有清楚方向和目标吗？ | 是 | 可能 `swing` |
| 突破后有强 `follow-through` 吗？ | 是 | 可能 `swing` |
| 能接受正常回调，不会乱砍吗？ | 是 | 才能 `swing` |

### `scalp` 规则

- 目标小，通常参考 `average bar size`
- 赚到目标就走，不要临时升级成波段
- 利润不能大幅回吐
- 不要在区间中间频繁做
- 失败要快走

### `swing` 规则

- 必须有大背景支持
- 必须有更远目标
- 可以忍受正常回调
- 不能因为第一根反向 K 就乱走
- 但如果原始逻辑被破坏，必须走

## 7. 第七步：入场前先写 stop 和 target

一笔合格交易，入场前至少能写出这三句话：

```text
我做这笔，是因为：____
如果价格到 ____，说明我错了。
如果价格到 ____，我至少先减仓或止盈。
```

### `initial stop` 放在哪里

- 区间下沿多单：放在真正失败的位置外，不是随便前低外 1 tick
- 区间上沿空单：放在真正突破成立的位置外
- 趋势回调顺势：放在回调结构被破坏的位置外
- 反转交易：放在反转 setup 被否定的位置外
- 宽通道交易：可以给假突破留空间，但必须缩仓
- 保护性退出默认用 `stop market`：跳空时成交价可能更差，但 `stop limit` 可能完全不成交；除非明确接受仓位留在场内的风险，否则不要把两者当作可互换的止损。

### `target` 先看哪里

- 区间交易：先看区间中部、对侧前高前低、缺口、EMA 附近
- `failed breakout scalp`：先看失败后的快速回弹/回落，不看太远
- 趋势交易：先看 `measured move`、前高前低、通道边界
- 期权交易：还要考虑 `theta`，接近收盘不能只看方向

## 8. 第八步：仓位跟止损距离一起算

不是“我看得准所以可以重仓”，而是：

```text
单笔可亏金额 / 每股或每张合约风险 = 仓位
```

举例：

```text
账户允许单笔亏 200 美元
这笔从入场到止损每股风险 2 美元
最多只能做 100 股
```

如果止损距离变宽，仓位必须变小。

### 仓位太大的信号

- 进场后每根 K 都让你紧张
- 还没到 stop 就想先砍
- 明明是 `swing`，却按 `scalp` 情绪出场
- 一亏就想加仓摊平
- 不敢承认原计划已经失败

仓位的目标不是让你赚得刺激，而是让你能客观看盘。

## 9. 第九步：持仓中只问三件事

进场后，不要每根 K 都重新发明一套逻辑。

### 继续拿

- 原始入场理由还在
- 没有打到失效点
- `follow-through` 还可以
- 回调只是正常回调，不是结构破坏
- 目标还没到

### 减仓或保护利润

- 第一目标到了
- 已有利润很大，但走势开始重叠
- 期权 `theta` 开始明显吞利润
- 趋势变成宽通道或震荡
- 出现 `buy climax / sell climax`

### 直接退出

- 原始假设被证伪
- 突破失败，且反向开始有跟随
- `swing` 逻辑消失，只剩祈祷
- 仓位让你无法按计划执行
- 你发现入场理由其实讲不清

## 10. 九种常见机会的简版对照

### A. 区间下沿做多

能做：
- 位置在下沿
- 下破失败
- 空头没有跟随
- 出现多头 trigger

不能做：
- 区间中间
- 只是跌多了
- 没有 trigger
- 想直接拿成大趋势

### B. 区间上沿做空

能做：
- 位置在上沿
- 上破失败
- 多头没有跟随
- 出现空头 trigger

不能做：
- 只是觉得贵
- 趋势已经强突破
- 空在区间下沿
- 止损太远但仓位不降

### C. `Always In Long` 顺势做多

能做：
- 市场已经明显偏多
- 回调没有破坏趋势
- 有好的 signal bar 或 pullback trigger
- 目标空间还够

不能做：
- 还没确认偏多就追
- 大级别看多，小级别没有 trigger
- 后面开始 `inside bar`、`overlap`、不创新高还死拿

### D. 大级别偏多，短线做空

能做：
- 关键压力位连续失败
- 已经出现 `third push`
- 短线从趋势变震荡
- 选更弱标的表达空头
- 仓位明显缩小

不能做：
- 只是觉得太高
- 第一次摸压力就空
- 工具很暴躁但仓位没缩

### E. `sell climax / exhaustion gap` 后做多

能做：
- 前面连续下跌
- 又出现最后一脚大阴线
- 缺口很快回补
- 空头开始失望
- 有 bullish trigger

不能做：
- 看到大阴线立刻抄底
- 还没有空头失败证据
- 把反弹误判成新趋势

### F. `failed breakout` 反手 scalp

能做：
- 原本就是区间
- 突破后立刻失败
- 失败很清楚
- 目标很近

不能做：
- 把 scalp 拿成 swing
- 进场后不肯快出
- 失败不明显就硬反手

### G. 强趋势后反转

能做：
- 趋势已走很久
- 到目标位或通道边界
- 第一次反转失败
- 第二次反转信号更好
- `reward/risk` 足够好

不能做：
- 第一次反向 K 就猜顶猜底
- 只因为止损小就做
- 没有足够目标空间

### H. 宽通道加速突破失败

能做：
- 当前是 `broad channel`
- 末端出现 `acceleration breakout`
- 5 根 K 内不能延续
- 小周期已经转向
- 止损和目标清楚

不能做：
- 通道很窄、趋势还强
- 只因为涨快就空
- 小周期仍有强跟随

### I. 窄区间日 scalp

能做：
- 当天波动很小
- 价格在区间边缘
- 平均 K 线目标清楚
- 能接受快进快出

不能做：
- 想拿大波段
- 区间中间乱做
- 看到大 K 就追
- 每一两根 K 都想交易

## 11. 下单前最终 12 问

每次下单前，逐条回答：

1. 现在是 `trend`、`trading range`、`broad channel`，还是 `narrow range day`？
2. 我现在的位置有优势吗？
3. 我做的是顺势、区间反向、突破失败，还是趋势后反转？
4. 这根大 K 是 `continuation`，还是 `climax`？
5. 我的 trigger 是什么？
6. 突破后有没有 `follow-through`？
7. 这笔是 `scalp` 还是 `swing`？
8. 第一目标在哪里？
9. 初始止损在哪里？
10. 按这个止损距离，我的仓位是否还能接受？
11. 如果错了，我会在哪里承认？
12. 如果对了，我会在哪里先兑现一部分？

只要有 3 个以上答不上来，这笔单先跳过。

## 12. 最短版本

```text
先判环境：
trend / trading range / broad channel / narrow range day

再判位置：
上沿 / 下沿 / 中间 / 通道边缘 / 目标位附近

再判动作：
continuation / climax / failed breakout

再等 trigger：
signal bar / double top-bottom / higher low-lower high / second entry

再看 follow-through：
有跟随才可能拿，没跟随就降级或放弃

最后定交易方式：
scalp 还是 swing
target 在哪里
initial stop 在哪里
仓位能不能承受
```

一句话：

**先过滤掉烂位置和讲不清的机会，再只做能写出 trigger、target、stop、position sizing 的交易。**
